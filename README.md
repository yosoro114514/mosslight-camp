# 苔灯营地

Godot 4.4.1 竖屏塔防。Windows 64 位双击 `dist/MosslightCamp.exe`。在编辑器中导入 `project.godot` 后按 F5 可运行。

启动后点击「进入营地」开始布阵。已有存档时，标题页会显示关卡、床铺生命和种子。点「继续守夜」恢复进度，或点「重新开始」，确认后从第一关布阵并覆盖旧进度。回车或空格默认进入或继续游戏。标题页左上角的「怪物图鉴」随时可看，点「返回」或按 Esc 回到标题页。

第一次玩可以在标题页点「新手教程」。跟着棋盘上的金圈种植叶狐，按住查看射程，再拖动合成。用霜兔减速守住入口，开战后用击败怪物赚到的种子部署雷羽鸮。练习只打一波，使用独立的阵容与种子，随时点「退出」或按 Esc 返回标题。练完点「进入正式营地」即可开始新局或接着原来的检查点玩。

布阵或战斗时，点下方「守夜手册」可以查布阵操作、四种伙伴、训练与超进化、波次与重试。阅读时战斗暂停，点「返回」或按 Esc 继续。

营地有循环配乐。种植、合成和四种伙伴的攻击各有音效，Boss 登场、床铺受损和守夜结算也有声音提示。点右上角的喇叭可切换静音，设置会保留到下次打开。网页版点「进入营地」或「继续守夜」后开始播放。

## 在 GitHub Pages 发布网页版

1. 将本项目放入 GitHub 仓库的 `main` 分支，保留 `.github/workflows/pages.yml`。若使用其他发布分支，修改该文件的 `on.push.branches`。
2. 在仓库的 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。
3. 打开 **Actions → Publish game to GitHub Pages → Run workflow**，选择发布分支运行一次。之后每次推送到发布分支都会自动重新导出并部署游戏。
4. 点击部署记录中 `github-pages` 的网址即可试玩。普通项目仓库的默认地址形如 `https://用户名.github.io/仓库名/`。

本地预览可用 Godot 4.4.1 安装对应导出模板，创建 `dist/web` 目录，运行 `godot --headless --import` 和 `godot --headless --export-release Web dist/web/index.html`。每次导出 Web 发布版后运行 `python tools/fix_webgl_handles.py dist/web/index.js`，使绘制战斗特效时释放的 WebGL 编号可供复用。GitHub Pages 构建会自动执行这一步。在项目根目录运行 `python -m http.server 8000 --bind 127.0.0.1 --directory dist` 后访问 `http://127.0.0.1:8000/web/`。网页进度保存在当前浏览器中。

## 无尽守夜

每关三波，第三波的普通敌人全部离场后，金冠岩壳龟 Boss 登场。床铺初始有 5 点生命，每个漏怪（含 Boss）扣 1 点。结算时床铺仍有生命即可进入下一关。沿用棋盘位置、伙伴种类、等级、剩余种子和训练等级，另补给 3 枚种子、修复 1 点床铺生命，上限为 5。

关数没有预设终点。每关在第一关的基础生命上再加 40%，适用于普通敌人和 Boss。后续关卡变换出场顺序并扩编每波队伍，基础队伍最多增加 8 只，再按场上战力调整；出怪间隔和移动速度逐渐提高节奏。第一关有蘑菇怪、疾翅蛾、岩壳龟，第二关加入会冲刺的赤角甲虫，第三关加入约每 2.4 秒恢复 10% 最大生命的苔灵。每关保留独立 Boss 血条。

## 布阵与成长

每波开始时按场上伙伴和训练估算战力。相对同关同波的基础值，普通敌人和 Boss 的生命倍率为 0.8～500 倍。从第 4 关起，高出该波预期两倍的那部分战力会逐关推高血量，第 10 关达到完整增长速度。普通敌人数最多增至 5 倍，出怪频率最多增至 4 倍。布阵和波间可预览下一波的生命倍率、普通敌人数和出怪间隔。开波时三项一起锁定，第三波末尾仍只出现一只 Boss。

从第 4 关起，敌人和 Boss 出场时会带金色护环。护环随行进距离缩短，减伤和加速在走完全程的 35% 时消失。护环逐关增强，第 10 关起在出口处减伤 85%、移速提升 42.5%。入口火力仍能削减血量，沿路部署的伙伴可以在护环减弱后补刀。

选上方的伙伴，用「部署等级」两侧的 − / + 选择 1 至 5 级，再点空格种植。各级每只分别花 3、7、15、31、63 枚种子，手动与自动种植共用 2.5 秒种植冷却。击败任一敌人得 2 枚种子。按住伙伴查看射程，拖到空格换位，拖到同种同级伙伴合成，最高 5 级。布阵时可拖回顶部伙伴栏撤回，按等级返还 1、2、4、8 或 16 枚种子。

| 伙伴 | 作用 |
| --- | --- |
| 叶狐 | 三把旋刀扫过整个圆面。升级提升伤害、加宽刀面并换色，各级攻击半径一致。 |
| 霜兔 | 霜环群攻并减速 40%，升级可延长减速。 |
| 雷羽鸮 | 优先攻击最接近床铺的射程内敌人，闪电可跳到附近其他敌人，最多命中三个目标。 |
| 松针猬 | 射程最远，优先攻击当前生命最高的敌人，适合岩壳龟和 Boss。 |

点底部「自动布阵」开启或关闭托管。布阵和战斗中都可用。有可合成的伙伴时优先合成。需要补位时，托管按当前种子数购买能负担的最高等级，不足 3 枚就等待。面板会显示自动种植的等级和价格，手动点格仍用自己选的等级。托管优先在道路拐角种植。切换上方伙伴即可改变自动种植的种类。按住棋盘或按钮时托管会让出操作，开关状态随存档保留。

右下角训练按钮每次花 18 枚种子，全队基础攻击伤害增加 1，可跨关累积。战斗中可继续种植、合成、训练，并切换一倍或两倍速。

### 满级超进化

将一只 5 级伙伴手动拖到另一只同种、尚未超进化的 5 级伙伴上，战斗会暂停。点选形态后消耗拖入的伙伴，点取消则保留两只。首次成功率为 65%。失败会给目标留下「保」徽记，下次以它为目标时任选形态都必成。换位时保底随伙伴移动。自动布阵会留下满级伙伴，供玩家手动选择。

| 伙伴 | 强攻形态（每击攻击 ×4） | 群攻形态（每击攻击 ×2） |
| --- | --- | --- |
| 叶狐 | 赤焰刃狐 | 六刃风狐，旋刀从三把增至六把 |
| 霜兔 | 绯晶霜兔 | 极夜雪兔，霜环半径增加 50%，减速延长 2 秒 |
| 雷羽鸮 | 天罚雷鸮 | 风暴雷鸮，闪电最多命中六只，每跳保留 85% 攻击并向上取整 |
| 松针猬 | 陨星针猬 | 飞棘针猬，重针最多依次命中三只，每次弹射保留 85% 攻击并向上取整 |

形态倍率作用于含训练加成的攻击，再按目标防御力或法抗结算。成功后的伙伴获得「超」徽记、持续环绕光效和形态攻击特效。形态与保底随阵容写入检查点。战斗中重试仍回到开战前的阵容。

## 防御力与法抗

布阵或战斗时，点「怪物图鉴」可查看五种普通怪物和金冠岩壳龟 Boss 的出场关卡、生命、移速、防御、法抗和特性。查看期间游戏暂停，点「返回」或按 Esc 可按原速度继续。普通怪物的生命和移速按本波基础值显示倍率，Boss 显示第一关的基础生命和移动速度。

每种怪物在 `data/enemies/` 下有一个 Godot 资源文件。可在编辑器的检查器中修改名称、立绘、图鉴说明和战斗属性。甲虫的冲刺周期、时长与速度倍率、苔灵的回血周期与比例也在对应资源中配置。

叶狐的每次刀刃命中、松针猬的每根重针都单独扣除目标的固定防御力。超过防御的部分直接扣血，攻击力等于或低于防御时会飘出「格挡」。例如一级叶狐对防御 1 的岩壳龟每刀都会被格挡，训练一次后每刀造成 1 点伤害。

霜兔和雷羽鸮的法术伤害等于该次攻击力乘以（1 − 目标法抗）。雷羽鸮每一跳按命中目标的法抗结算。霜兔的减速幅度和持续时间独立于法抗。敌人生命保留到百分位，头顶和 Boss 血条的数字向上取整。

敌人受到物理伤害时会迸出金色火花，受到法术伤害时会亮起紫色光环。同色飘字显示这次实际扣掉的生命，计入防御、法抗和入场保护，最多保留两位小数。致命一击显示目标当时的剩余生命。完全格挡时出现蓝色盾弧，飘字只显示「格挡」。受击动作沿攻击方向轻摆，强度随本次扣血占最大生命的比例变化。

| 敌人 | 防御力 | 法抗 |
| --- | ---: | ---: |
| 蘑菇怪 | 0 | 0% |
| 疾翅蛾 | 0 | 25% |
| 岩壳龟 | 1 | −20% |
| 赤角甲虫 | 1 | 0% |
| 苔灵 | 0 | 35% |
| 金冠岩壳龟 Boss | 2 | −20% |

## 存档与重试

布阵调整、开战和通关时都会在 Godot 的本地用户数据目录保存检查点。战斗中退出，下次点「继续守夜」会回到本关开战前的布阵。通关结算时退出，继续时会进入下一关布阵。

布阵或战斗时，点右上角「重开」会暂停游戏。战斗中选「重试本关」可回到开战前的布阵和资源；点「取消」或按 Esc 可继续。选「从第一关重新开始」会覆盖当前进度，回到满生命、6 枚种子和一只 1 级叶狐的初始布阵。通关和失守结算页也能重开。
